# PRD: 情侣互动小游戏合集「心动回合战」

> 阶段 2 产出 · 全栈开发大师流程
> 日期：2026-09-08
> 状态：待确认

## 1. Introduction / 概述

「心动回合战」是一款面向情侣的**单设备轮流**互动小游戏合集。通过骰子、任务卡、真心话、大转盘、默契问答等多种玩法，在"大胆热恋风"但不越界的氛围中促进情侣感情升温。

应用为**纯前端单页应用**，无需注册登录、无需后端，打开即玩。v1 版本包含三种核心玩法模式，并预留可扩展接口，后续可接入更多更大胆的互动玩法。

## 2. Goals / 目标

- 让情侣在 10~20 分钟一局的游戏中获得高频亲密互动体验
- 提供至少 3 种玩法模式，覆盖"挑战型""运气型""默契型"三类互动
- 支持多套视觉主题风格自由切换，适配不同情侣偏好
- 内置音效，支持自定义背景音乐
- 纯前端部署，手机/桌面浏览器均可使用
- 预留内容扩展接口，后续可持续添加新玩法与新卡牌库

## 3. User Stories / 用户故事

### US-001: 开箱即玩首页
**Description:** 作为一对情侣，我打开应用即可看到游戏首页，选择玩法模式后直接开始，无需注册登录或填写设置。

**Acceptance Criteria:**
- [ ] 首页展示应用名称与 3 个玩法模式入口卡片
- [ ] 点击任一模式直接进入对应游戏，无中间设置步骤
- [ ] 首页提供"主题切换"和"音乐设置"的轻量浮窗入口（不阻塞游戏开始）
- [ ] 移动端和桌面端均可正常显示首页
- [ ] Verify in browser

### US-002: 心动回合战 - 核心玩法
**Description:** 作为一对情侣，我们想轮流掷骰子、抽卡完成挑战并获得心动值，体验快节奏的亲密互动。

**Acceptance Criteria:**
- [ ] 进入后显示两个玩家区域（默认昵称"TA"和"宝贝"），高亮当前回合玩家
- [ ] 当前玩家点击"掷骰子"按钮，骰子有滚动动画，停止后显示点数
- [ ] 骰子点数映射到挑战类型：1-2=任务卡，3-4=真心话，5=惩罚轮，6=奖励卡
- [ ] 抽取对应卡牌并展示内容，玩家完成挑战后点击"完成"获得心动值
- [ ] 完成任务得 10 分，真心话得 8 分，惩罚得 12 分，奖励卡得 15 分
- [ ] 连续完成 3 次挑战触发"连击"特效，额外加 5 分
- [ ] 每玩家 5 回合后游戏结束，展示双方心动值与浪漫结算文案
- [ ] 可随时点击"重新开始"重置一局
- [ ] Verify in browser

### US-003: 命运大转盘
**Description:** 作为一对情侣，我们想转动命运转盘，根据落点执行亲密互动，体验随机惊喜感。

**Acceptance Criteria:**
- [ ] 大转盘分割为 8 个扇区，每个扇区标注事件类型（亲吻/拥抱/壁咚/撒娇/提问/小惩罚/奖励/再转一次）
- [ ] 点击"转动"按钮后转盘有旋转动画，逐渐减速停在随机扇区
- [ ] 停止后弹出对应事件的任务描述卡片
- [ ] 玩家执行后点击"完成"关闭卡片，可继续转动
- [ ] 转盘扇区内容每次进入可随机打乱顺序
- [ ] Verify in browser

### US-004: 默契问答
**Description:** 作为一对情侣，我们想通过快问快答测试彼此的默契程度，答错触发亲密小任务。

**Acceptance Criteria:**
- [ ] 两人轮流回答同一道关于对方的问题（如"TA最喜欢的食物是什么"）
- [ ] 一人先回答，另一人再回答，系统对比两答案是否一致
- [ ] 答案一致显示"心有灵犀"特效，双方各得 10 分
- [ ] 答案不一致显示"默契不足"，触发一张随机亲密任务卡作为"惩罚"
- [ ] 每局 10 道题，结束后展示默契度百分比与评价
- [ ] Verify in browser

### US-005: 多主题风格切换
**Description:** 作为用户，我想自由选择不同的视觉主题风格，适配我和伴侣的喜好。

**Acceptance Criteria:**
- [ ] 至少内置 3 套主题：甜蜜粉嫩风、深夜浪漫风、活力多彩风
- [ ] 主题切换通过首页浮窗或设置面板操作，即时生效无需刷新
- [ ] 主题包含配色、背景、卡片样式、字体色调的整体变化
- [ ] 主题选择持久化到 localStorage，下次打开保持上次选择
- [ ] Verify in browser

### US-006: 音效与背景音乐
**Description:** 作为用户，我想在游戏中有音效反馈和背景音乐，且背景音乐可以自定义。

**Acceptance Criteria:**
- [ ] 关键操作播放音效：掷骰子、抽卡、得分、连击、转盘停止
- [ ] 背景音乐默认关闭，可手动开启
- [ ] 提供背景音乐上传入口（本地文件选择），支持循环播放
- [ ] 音效和音乐各有独立音量控制
- [ ] 音量设置持久化到 localStorage
- [ ] Verify in browser

### US-007: 卡牌库内容管理（内置）
**Description:** 作为系统，需要内置足够丰富的卡牌内容以支撑多局游戏不重复。

**Acceptance Criteria:**
- [ ] 任务卡库 ≥ 40 条，真心话库 ≥ 40 条，惩罚卡库 ≥ 20 条，奖励卡库 ≥ 15 条
- [ ] 默契问答题库 ≥ 30 条
- [ ] 转盘事件描述 ≥ 8 条（每扇区至少 1 条）
- [ ] 卡牌抽取有防短期重复机制（最近 10 张不重复抽取）
- [ ] 所有内容均为"大胆热恋风"，含蓄浪漫不露骨，无不良引导
- [ ] 卡牌库数据结构统一，存储在独立 JSON 文件中，便于后续扩展

### US-008: 玩法扩展接口预留
**Description:** 作为开发者，我需要预留玩法扩展接口，后续可快速接入更多更大胆的互动玩法。

**Acceptance Criteria:**
- [ ] 每种玩法封装为独立模块，遵循统一的玩法接口规范（init/start/end/reset）
- [ ] 首页模式列表从配置注册表动态渲染，新增玩法只需注册不需改首页
- [ ] 卡牌库支持标注"内容等级"字段（如 sweet / hot / wild），为后续分级开关预留
- [ ] 文档中记录玩法接口规范，便于后续开发参照

## 4. Functional Requirements / 功能需求

- **FR-1**: 应用为纯前端单页应用（SPA），无后端依赖，无需登录
- **FR-2**: 首页展示模式选择入口，点击直接进入对应玩法
- **FR-3**: 心动回合战模式：双人轮流掷骰 → 抽卡 → 完成挑战 → 计分 → 连击 → 结算
- **FR-4**: 命运大转盘模式：8 扇区转盘随机停止 → 弹出事件卡 → 执行后继续
- **FR-5**: 默契问答模式：双人轮流答题 → 对比答案 → 一致得分/不一致惩罚 → 结算默契度
- **FR-6**: 至少 3 套视觉主题，支持即时切换并持久化
- **FR-7**: 内置音效系统（骰子/抽卡/得分/连击/转盘），支持开关与音量控制
- **FR-8**: 背景音乐支持本地文件上传、循环播放、独立音量控制
- **FR-9**: 所有偏好设置（主题、音量）持久化到 localStorage
- **FR-10**: 卡牌库存储为独立 JSON 文件，支持内容等级字段标注
- **FR-11**: 玩法模块遵循统一接口规范，支持动态注册到首页模式列表
- **FR-12**: 移动端优先适配，兼容桌面浏览器
- **FR-13**: 卡牌防短期重复抽取机制

## 5. Non-Goals / 不在范围内

- **不做**：用户注册登录系统
- **不做**：后端服务器与数据库（纯前端）
- **不做**：异地联机对战（v2 预留，v1 不实现）
- **不做**：用户自定义卡牌编辑（v2 预留）
- **不做**：内容分级开关 UI（v2 预留，v1 仅在数据层标注等级字段）
- **不做**：社交分享功能
- **不做**：排行榜系统（纯本地无竞争需求）

## 6. Design Considerations / 设计考量

### 视觉风格
- **甜蜜粉嫩风**：粉红/玫红主色调，圆润边角，心跳元素装饰，可爱温馨
- **深夜浪漫风**：深紫/暗红主色调，轻奢质感，微光效果，成熟浪漫
- **活力多彩风**：多彩渐变，emoji 丰富，派对感，青春活力

### 交互设计
- 移动端优先：大按钮、触摸友好、竖屏最优
- 动效反馈：骰子滚动、卡牌翻转、转盘旋转、心跳脉动
- 游戏中顶部常驻：当前模式名、双方分数、回合计数
- 卡牌展示全屏居中，带有翻转/淡入动画

### 内容风格
- 大胆热恋风：亲吻、拥抱、壁咚、撒娇等亲密互动
- 文案含蓄、浪漫、幽默，不露骨，无不良引导
- 中文界面与中文卡牌内容

## 7. Technical Considerations / 技术考量

- **技术栈**：纯前端 SPA（Vue 3 + Vite 或原生 HTML/CSS/JS，阶段4架构设计确定）
- **数据存储**：localStorage 存偏好设置；卡牌库为静态 JSON 文件
- **音效**：使用 Web Audio API 或 HTML5 Audio
- **动画**：CSS 动画为主，复杂动效用 Canvas 或第三方库
- **部署**：静态文件托管（GitHub Pages / EdgeOne Pages 等）
- **预留扩展**：玩法模块化、卡牌等级字段、接口规范文档化

## 8. Success Metrics / 成功指标

- 一局游戏 10~20 分钟可完成，互动高潮频率 ≥ 每 2 分钟一次
- 3 种玩法模式全部可独立正常运行
- 卡牌库内容足够支撑 5 局以上不出现明显重复
- 在手机浏览器（Chrome/Safari）和桌面浏览器均流畅运行
- 多主题切换无布局错乱
- 页面首屏加载 < 3 秒（静态资源）
