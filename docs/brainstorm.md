# 头脑风暴记录：情侣互动小游戏合集「心动回合战」

> 阶段 1 产出 · 全栈开发大师流程
> 日期：2026-09-08

## 1. 项目背景与目标

为情侣打造一款**单设备轮流**的亲密互动小游戏合集，通过"大胆热恋风"但不越界的任务与互动，促进情侣之间的感情升温。应用无不良引导，内容健康、浪漫、有趣。

**核心目标**：
- 让情侣在轻松愉快的游戏氛围中增加互动、亲密感与默契
- 覆盖"骰子、任务卡、真心话、惩罚轮"等多种玩法，可扩展
- 纯前端单页应用，无需后端，打开即玩，可部署到静态托管

## 2. 核心决策（来自用户确认）

| 维度 | 决策 |
|------|------|
| 玩法形态 | 单设备轮流（两人同屏，你一下我一下） |
| 内容尺度 | 大胆热恋风：亲吻、拥抱、壁咚、撒娇等亲密互动任务，文字含蓄不露骨，无不良引导 |
| 玩法构成 | 骰子 + 任务卡 + 真心话 + 惩罚轮为主框架，内置转盘 / 默契问答等更多互动小游戏 |
| 整体方案 | 方案 A「心动回合战」为主框架，内置多玩法（转盘、问答等） |
| 技术栈 | 纯前端单页应用（HTML/CSS/JS 或 Vue3，无需后端） |
| 部署 | GitHub 仓库 + 静态托管（可后续接入 EdgeOne Pages 等） |

## 3. 玩法设计草案

### 3.1 主框架：心动回合战
- 两人轮流操作，每回合由当前玩家**掷骰子**决定挑战类型（任务 / 真心话 / 惩罚 / 奖励）
- 抽到对应卡牌后，玩家完成挑战，获得 **心动值**
- 累积心动值、连击加成、回合数限制，一局 10~20 分钟
- 游戏结束展示心动值排行与浪漫结算

### 3.2 内置小游戏（可扩展）
1. **命运大转盘**：转盘指针落点决定事件（亲吻、拥抱、小惩罚、提问……）
2. **默契问答**：快问快答/默契测试，答错触发亲密任务
3. **真心话轮盘**：指定真心话题目库，轮流回答
4. **惩罚轮**：趣味小惩罚（做鬼脸、学猫叫、被挠痒等）与大冒险

### 3.3 内容分级与文案
- 任务卡 / 真心话 / 惩罚卡内容按"大胆热恋风"编写
- 保持含蓄、浪漫、幽默，无露骨、无不良引导
- 全部文案为中文，可后续扩展分级开关（纯洁版/热恋版）

## 4. 用户故事（草案）

- 作为一对情侣，我打开应用即可进入游戏，无需注册登录
- 我可以选择游戏模式（心动回合战 / 转盘 / 默契问答 / 自定义抽卡）
- 我可以轮流掷骰子、抽卡，完成挑战获得心动值
- 我可以看到当前回合、双方分数、连击状态
- 我可以随时查看游戏历史或重新开始一局
- 我可以调整内容分级（可选）与音量/音效

## 5. 关键约束

- 纯前端：无后端、无数据库、无登录（数据可存 localStorage）
- 移动端优先（手机同屏轮流），兼容桌面浏览器
- 文案健康、积极，符合"促进感情升温"的正向目标
- 未来可扩展：异地联机（需后端）、图片/动效、更多卡牌库

## 6. 待定项（进入阶段2 前澄清）

- 是否需要音效 / 背景音乐（可选）
- 是否需要"今日情侣打卡"之类的留存玩法
- 是否需要自定义卡牌（用户自己添加任务内容）
- 语言：中文界面
